## 一、第一个小标题

这里是正文，用 Markdown 写。

普通段落直接写文字就行。

- 无序列表用 `-` 开头
- 第二项

1. 有序列表用 `1.` 开头
2. 第二项

> 引用 / 想强调的句子，用 `>` 开头

**加粗** 用两个星号包起来，`行内代码` 用反引号包起来。

## 二、代码块

代码块用三个反引号围起来：

```

```

## 三、图片

### 分类可选值（category 字段，六选一）

- 入门/框架
- 电机控制
- 平衡轮腿
- 底盘/云台
- 比赛复盘
- 踩坑记录

### 字段说明

- `title`：文章标题（必填）
- `date`：日期，格式 2026-08-18（必填）
- `category`：分类，从上面六选一（必填）
- `tags`：标签，逗号分隔（可选）
- `slug`：英文短名，决定生成的文件名 post-xxx.html（必填）
- `excerpt`：首页摘要（可选，不写自动生成）

写完保存后，在 blog 目录下运行：`node build.js`
